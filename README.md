# BLD/PAIRS

I'm learning 3x3 blindfolded and didn't enjoy keeping an Excel sheet for my letter pairs, so this helps solve that annoyance.
All 552 Speffz pairs are in there with preset words. You can edit anything you don't like with your own words, saved on browser with the ability to import/export pairs. 

Visit the live site [here](https://bldtrainer-sigma.vercel.app/).
